# 2026-08-20

## Rust Agent API shared-client migration

- Added one generated-contract-backed `AgentTransport` to the existing
  `AomiClient` for start/check/interrupt/action result and session CRUD.
- Migrated the existing `ClientSession` to AgentDelta/cursor polling by
  default, including stable message upserts, refresh recovery, typed EVM/SVM/
  signing actions, partial EVM batch results, and direct action resolution.
  The old transport remains only as the explicit `transport: "legacy"`
  rollback/test adapter; no parallel V1 session class was introduced.
- Migrated the existing AomiClient thread helpers onto Agent sessions while
  preserving their public compatibility return shapes. Fresh session creation
  is owned by the first Agent start rather than a second legacy create call.
- Added a checked Rust OpenAPI snapshot plus generated TypeScript types and a
  freshness check that executes `api-server --print-openapi`; TypeScript does
  not own a parallel protocol document.
- Verified 77 focused client tests, generated-contract freshness, TypeScript
  compilation, and the distributable client/CLI build.

## Agent CLI and React runtime cutover

- Moved CLI chat/check/sessions/interrupt/history and action execution onto the
  shared `ClientSession`/`AgentTransport`, including model-on-start, EVM batch
  hashes, EVM/SVM signing, and exact submitted/failed/skipped SVM batch legs.
- Preserved old on-disk wallet requests through one explicitly named CLI
  rollback adapter; normal CLI source no longer calls legacy Agent state or
  free-form system-message APIs.
- Moved React model/app selection onto the next canonical Agent start, removed
  the separate model mutation from normal runtime behavior, and carried live
  wallet state through `ClientSession` rather than automatic legacy callbacks.
- Added automated web and CLI partial SVM batch tests and kept generic system
  commands behind an explicitly named React rollback adapter.
- Updated Portal payment interception and locked-app scoping for
  `/v1/agent/chat` while retaining the old chat URL as a rollback-only alias.
- Verified the complete client/React unit surface (487 passing, 28 intentionally
  skipped integration tests), 20 Portal proxy/payment tests, 11 web transaction
  handler tests, Portal type-check, and client/React/widget distributable builds.
