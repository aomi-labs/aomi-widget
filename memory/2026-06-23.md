# 2026-06-23

- Added `GET /api/mcp/token` in the portal BFF to mint a short-lived user AccountBearer from the current `aomi_session` cookie for remote MCP client setup. The route uses the existing `getSessionedCanonicalId` + `mintAccountBearer` seam and does not proxy MCP traffic.
- Added `/mcp/connect` as a manual browser flow for connecting Claude/remote MCP: sign in through the existing portal session bridge, mint a short-lived MCP bearer, and copy the Authorization header or config JSON.
