  restored its bot icon in the compact selected trigger.

  artifact is not ready.

  package build, and `git diff --check`.

## Orchestrator working-trace scrolling

- Fixed the capped working-trace viewport so live nested subagent steps trigger
  the same follow-latest scroll and overflow remeasurement as top-level trace
  rows. Previously a subagent remained one top-level item, leaving the parent's
  `revealed` count unchanged while its child rail grew.
- Added a focused DOM regression covering scroll-to-latest, keyboard-scroll
  eligibility, and the restored “Show all” affordance after child-step growth.
- Refreshed the `assistant-thread` registry artifact and verified the focused
  test, targeted ESLint/Prettier, widget package build, and `git diff --check`.
- Sanitized completed-agent summaries at the UI boundary: ordinary prose still
  renders, structured returns expose only explicit `summary`, `message`, or
  `reason` strings, and other JSON falls back to the staged count instead of
  leaking the parent-orchestrator payload into the compact row. Added two
  focused regressions for the hidden-object and named-summary cases.
- Removed the redundant `Orchestrating · ORCHESTRATOR` header wording. The
  status now uses the same `Working`/`Worked…` copy as direct mode while the
  existing blue badge remains the single orchestration-mode indicator.
- Closed the remaining structured-summary leak shown in a live screenshot:
  `TaskCompleted` truncates long messages to its wire budget, so JSON-shaped
  returns can arrive invalid and had hit the parser's prose fallback. Any
  object/array-shaped completion now stays hidden even when clipped; a focused
  malformed/truncated JSON regression preserves the staged-count fallback.
- Styled the staged-count fallback as `Staged N` and prefixed it with the same
  Layers glyph used for staging work elsewhere in the trace. Covered live
  sidecar and transcript-only completed-agent variants.
- Refined completed-agent results after UI review: the row now prefers a
  readable, naturally truncated preview of the exact child return instead of
  `Staged N`. Structured objects become scalar fact prose such as
  `Input: … · Output: …`; the larger-budget post-`thread_return` activity copy
  recovers results when the completion event was clipped. The same humanized
  return is retained as the final note in the expanded child rail, while the
  protocol tool and unrelated JSON narration stay hidden. `Staged N` remains
  only when no return message can be recovered.
