# 2026-05-04

- Added selectable payment methods to the widget stack. `@aomi-labs/client` now supports optional `paymentMethod` wire values (`null`, `byok`, `tempo`, `coinbase`) and forwards them as `/api/chat?payment_method=...`; `null` as an option value still means auto/omitted. `@aomi-labs/react` stores the selection per thread and propagates it through runtime sessions. The registry control bar now includes a compact Payment selector with Auto, Aomi credits, BYOK, MPP, and x402 options.
- Added TypeScript CLI `--payment-method` / `AOMI_PAYMENT_METHOD` with aliases matching the Rust CLI: `auto`, `null`, `byok`, `mpp`/`tempo`, and `x402`/`coinbase`.
