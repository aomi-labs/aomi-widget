# Agentic Application

An agentic application on Aomi combines:

- A prompt or system frame that defines the product behavior.
- A set of callable tools backed by APIs, SDKs, or on-chain actions.
- Execution controls such as session state, simulation, and signing policy.

For the broader platform framing, read [Build Overview](/docs/build/overview). For tool construction, read [Building Apps](/docs/build/services/building-apps).
