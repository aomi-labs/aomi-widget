# Non-Custodial Automation

Aomi can automate transaction preparation, simulation, and approval flows without holding user keys.

- The agent prepares or batches transactions.
- Simulation validates the expected state transition first.
- The user's wallet or configured signer authorizes execution.

For the deeper model, read [Non-Custodial Wallet](/docs/non-custodial-wallet) and [Account Abstraction](/docs/reference/account-abstraction).
