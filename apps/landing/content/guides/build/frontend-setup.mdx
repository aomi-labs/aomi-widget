# Frontend Setup

There are two supported frontend paths:

- [Widget Installation](/docs/build/widget-installation) if you want a ready-made chat surface.
- [Headless Library](/docs/build/headless-library) if you want to build your own UI.

If you are starting from zero, begin with [Quickstart](/docs/build/quickstart).
