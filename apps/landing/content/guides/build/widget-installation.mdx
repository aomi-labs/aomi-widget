# Widget Installation

The fastest way to embed Aomi is the bundled widget.

```bash
npx shadcn add https://aomi.dev/r/aomi-frame.json
```

Then follow [Quickstart](/docs/build/quickstart) and [AomiFrame](/docs/build/ui/widget/aomi-frame).
