# Widget Installation

The fastest way to embed Aomi is the compiled package widget:

```bash
npm install @aomi-labs/widget-lib
```

Then follow [Quickstart](/docs/build/quickstart) to configure Portal plus Para,
Privy, or providerless SIWE.

If you intentionally want source-owned shadcn components instead, install:

```bash
npx shadcn add https://aomi.dev/r/aomi-widget.json
```

Use [AomiFrame](/docs/build/ui/widget/aomi-frame) only for an advanced,
host-composed layout.
