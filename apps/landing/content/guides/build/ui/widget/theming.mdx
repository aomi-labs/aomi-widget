# Theming

Aomi components follow shadcn conventions. Package consumers first import the
precompiled stylesheet and override its CSS variables or wrap the widget with a
class. Registry consumers may also edit the copied component source.

```tsx
import "@aomi-labs/widget-lib/styles.css";
```

## CSS Variables

shadcn uses HSL CSS variables for theming. Define them in your global CSS:

```css
/* globals.css */
@layer base {
  :root {
    --background: 0 0% 100%;
    --foreground: 0 0% 3.9%;
    --primary: 0 0% 9%;
    --primary-foreground: 0 0% 98%;
    --muted: 0 0% 96.1%;
    --muted-foreground: 0 0% 45.1%;
    --border: 0 0% 89.8%;
    --ring: 0 0% 3.9%;
    --radius: 0.5rem;
  }

  .dark {
    --background: 0 0% 3.9%;
    --foreground: 0 0% 98%;
    --primary: 0 0% 98%;
    --primary-foreground: 0 0% 9%;
    --muted: 0 0% 14.9%;
    --muted-foreground: 0 0% 63.9%;
    --border: 0 0% 14.9%;
    --ring: 0 0% 83.1%;
  }
}
```

Components reference these variables through Tailwind:

```tsx
<div className="bg-background text-foreground border-border" />
```

## Dark Mode

Components use the `.dark` class for dark mode. Toggle with your preferred method:

```tsx
// Using next-themes
import { ThemeProvider } from "next-themes";

<ThemeProvider attribute="class" defaultTheme="system">
  <AomiWidget apiUrl="https://chat.aomi.dev" />
</ThemeProvider>;
```

Both light and dark variants are defined in the CSS variables above. The `.dark` class on a parent element activates the dark palette.

## Common Customizations

### Custom Colors

Override the color variables to match your brand:

```css
:root {
  --primary: 221.2 83.2% 53.3%; /* Blue */
  --primary-foreground: 210 40% 98%;
}
```

### Border Radius

Adjust the global radius variable:

```css
:root {
  --radius: 0.75rem; /* More rounded */
}
```

### Message Bubbles

Registry consumers can edit `components/assistant-ui/thread.tsx` directly:

```tsx
<div
  className={cn(
    "rounded-lg px-4 py-2",
    isUser ? "bg-primary text-primary-foreground" : "bg-muted",
  )}
>
  {content}
</div>
```

### Sidebar Width

Registry consumers can edit `components/assistant-ui/threadlist-sidebar.tsx`:

```tsx
<Sidebar className="w-64">  {/* Default is w-64 (256px) */}
```

### Frame Container

Add a class to `AomiWidget` (or the lower-level `AomiFrame`):

```tsx
<AomiWidget
  apiUrl="https://chat.aomi.dev"
  className="rounded-xl shadow-lg"
  style={{ height: "calc(100vh - 80px)" }}
/>
```

## The `cn` Utility

Use the `cn` helper (clsx + tailwind-merge) to merge classes conditionally:

```tsx
import { cn } from "@aomi-labs/react";

<div
  className={cn(
    "base-styles",
    isActive && "active-styles",
    className, // Allow overrides from props
  )}
/>;
```

## Best Practices

| Do                                | Don't                                           |
| --------------------------------- | ----------------------------------------------- |
| Import package CSS once           | Duplicate the compiled widget stylesheet        |
| Use CSS variables for colors      | Put server auth secrets in CSS/build config     |
| Use wrapper classes for layout    | Add package source scanning just for the widget |
| Edit source only in registry mode | Patch generated package bundles                 |
